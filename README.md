## 어려웠던 점 3가지와 해결 
1. 중간중간 과정 이해가 어려웠던 부분을 ai에게 개념부터 쉽게 설명해달라고 요청했더니 단계별로 천천히 알려줘서 이해할 수 있었다.
2. 평점 배지는 뜨는데 랭킹 배지가 뜨지않아 고민하던중 평점 배지 내용을 똑같이 했더니 랭킹 배지도 보였다.
3. 영어를 잘 못해서 영단어 의미가 어려울 땐 파파고 사용하고 파파고도 영 안되면 gpt를 사용했다.
